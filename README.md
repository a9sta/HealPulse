# 힐펄스 (HealPulse)

출장마사지·홈타이 방문 안내 정적 사이트. 외부 의존성 없이 Node 20 표준 라이브러리만 쓴다.

## 돌리는 법

```bash
npm run regions   # 행정동 경계 → data/regions.json (원본 geojson 필요)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 16종
npm run simil     # 동 페이지끼리 본문 겹침 측정
npm run serve     # dist/ 를 로컬에서 띄워 보기
```

## 이 사이트가 재는 값 — 테두리 분담

시군구 하나를 땅 한 덩어리로 보고, 그 **바깥 테두리를 안쪽 동네들이 몇 미터씩 나눠 맡는다**고
본다. 경계를 선분 단위로 쪼개 같은 시군구 안에서 맞춰 보고, 두 번 나오면 안쪽 경계,
한 번만 나오면 바깥 테두리로 센다.

| 값 | 뜻 |
|---|---|
| 맡은 길이 | 그 동네가 떠맡은 바깥 테두리의 길이(m) |
| 맡은 몫 | 시군구 테두리 전체에서 차지하는 비율(%) |
| 겉자리·속자리 | 바깥에 한 뼘도 닿지 않으면 속자리 |
| 제 둘레 중 바깥 비율 | 그 동네가 얼마나 열려 있는지 |
| 마주 보는 시군구 | 테두리 건너에 있는 시군구와 맞댄 길이 |

★꼭짓점이 아니라 **선분**을 맞춰야 길이가 나온다. 전국 테두리 합은 약 12,000km다.

## 커버리지

- **동까지** 서울·인천·경기·부산 — 1,232자리
- **시군구까지** 대전·대구·울산 전역 + 광주 광산구 + 지정 시·군
- 읍과 면은 페이지를 내지 않고 시군구 목록에 이름만 올린다(접수와 방문은 동일).

## 꼭 지킬 것

- `data/lastmod.json` 을 **반드시 커밋**한다. 없으면 깃 빌드에서 전 페이지가 '오늘 수정'으로 밀린다.
- 전화번호는 `callChip()` 으로만 찍는다. 맨 번호가 본문에 남으면 `npm run check` 가 잡는다.
- 무작위를 쓰지 않는다. 모든 변형은 md5 시드 고정이라 같은 주소면 언제나 같은 HTML 이 나온다.
- 후기·체험담·평점·인물 사진을 싣지 않는다.
